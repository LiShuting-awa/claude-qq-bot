# 战雷群聊黑话对照

群里聊战雷的时候不会说全称，下面这些是常出现的说法。
听懂这些比背数据有用——很多话字面上跟游戏没关系。

## 人和阵营

| 说法 | 意思 |
| --- | --- |
| 蜗牛 | Gaijin Entertainment，开发商。吐槽平衡和服务器时基本都用这个 |
| 壮丁 | 被拉进高出自己 BR 一档的房间 |
| 班长 | 房间里 BR 最高的人 |
| 苏系偏袒 / Russian Bias | 社区梗，指「苏系总被加强」的都市传说，吐槽用 |
| 队友 / 憨憨 | 指同队但帮倒忙的人 |

## 打法和局面

| 说法 | 意思 |
| --- | --- |
| 摆角度 | 车身斜着对敌，靠倾角增加等效装甲 |
| 卖头 | 只露炮塔，藏住车体（也称「卖铁头」） |
| 老六 | 蹲在角落阴人、专打路过的人 |
| 劝架 | 抢队友的人头，趁两边打得差不多时插进去 |
| 拉烟 | 发动机或车体被打冒烟，位置暴露 |
| 一发入魂 | 一发就打中弹药架，直接殉爆 |
| 打飞机 | 击落对面飞机；陆战里也指被飞机炸 |
| 开挂 / 沙雕挂 | 指责对方作弊，多数时候是情绪词不是事实判断 |
| 掉能量 | 空战里速度和高度都掉了，接下来只能挨打 |
| 单车 / 单机 | 一局只带一辆载具，死了就退 |
| 白给 | 白白送掉，没换到任何东西 |
| 血压 | 被气到，比如连输、被队友坑 |
| 破防 | 心态被打崩 |
| 拉了 | 表现很差、不行 |

## 经济相关

| 说法 | 意思 |
| --- | --- |
| 亏钱 | 一局打完修车费比收益高，净亏银狮 |
| 肝 / 肝线 | 反复打同一局刷研发点 |
| 氪 / 氪金 | 花钱买金币载具或高级账户 |
| 打钱车 | 收益高、专门用来赚银狮的车 |

## 该注意的

- 「开挂」「外挂」在群里绝大多数是情绪表达。除非有录像或数据，别跟着当事实说。
- BR、金币载具价格、活动规则这些每期都在动，任何具体数字都建议以游戏内为准。
- 群里说「蜗牛又搞事」时，通常是在吐槽某次平衡调整或更新，不是真的在讨论公司。
