# 网络黑话 / 梗对照表

用来听懂群里的短句。这些词多数**不是在说字面意思**，而是在表达态度。

## 反应类（大部分时候只是语气）

| 说法 | 意思 |
| --- | --- |
| yyds | 「永远的神」，夸，也可以反讽 |
| 蚌埠住了 / 绷不住了 | 忍不住笑了，或忍不住（情绪） |
| 乐 | 「笑死」，常带点看戏意味 |
| 典 | 「经典」，指某人的表现非常符合刻板印象，多为贬 |
| 急了 | 说对方情绪失控。**属于挑衅性用词**，被这么说不用接 |
| 破防 | 心态被打崩 |
| 血压 | 被气到 |
| 6 / 溜 | 厉害；单独一个「6」也可以是阴阳 |
| 抽象 | 形容离谱、无法理解的行为或言论 |
| 阴阳怪气 | 表面客气实际在挖苦 |
| 上强度 | 开始认真、加大力度 |
| 我裂开了 | 崩溃了 |
| 打脸 | 前面说的被事实推翻 |
| 降维打击 | 用高一个层级的手段碾压 |
| 遥遥领先 | 原为产品发布用语，现在多用来夸张或调侃 |
| 赛博 | 前缀，加在名词前表示「网络版的」，比如赛博许愿、赛博算命 |
| 老六 | 阴人、蹲人（源自射击游戏） |
| 拉了 | 不行了、表现差 |

## 该怎么处理

- 「急了」「典」「孝」这类词**指向人**，是挑衅。别顺着对骂，也别认真解释。
  一句冷处理，或者直接问正事。
- 「乐」「6」「抽象」大多是随口一说，不需要回。
- 群里的梗更新很快，遇到不认识的就说不认识，别硬猜意思——猜错比不知道更尴尬。
- 这些词在正经讨论里也可能出现（比如「这个方案有点抽象」），
  按上下文判断，不要一律当玩笑。
