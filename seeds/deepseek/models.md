# DeepSeek 是什么

深度求索，2023 年 7 月成立的中国 AI 公司，创始人梁文锋，与量化机构幻方（High-Flyer）渊源很深。
出名的方式不是发布会，而是**把模型权重开源 + 价格压到极低**。

## 模型线

- **DeepSeek-Coder**：早期专攻代码的系列。
- **DeepSeek-V2**：引入了 **MLA（多头潜在注意力）** 和 **DeepSeekMoE**，
  用更少的推理成本做到接近当时顶级的水平，也是它第一次因为「便宜」被大量讨论。
- **DeepSeek-V3**：MoE 架构，总参数量很大（约 671B 量级）但每次推理只激活其中一小部分
  （约 37B 量级），所以又快又省。训练成本被官方论文披露为几百万美元量级、用两千多张 H800，
  这个数字当时引起了很大讨论，因为它远低于外界对同级模型的成本预期。
- **DeepSeek-R1**：推理模型，特点是**主要靠强化学习**把长链推理能力练出来，
  而不是先堆大量人工标注的推理数据。同期还有 R1-Zero（不经过监督微调、纯 RL 的版本）。
  权重按 **MIT 协议**开源，并放出了一批蒸馏到更小模型（1.5B 到 70B 量级）的版本，
  让小团队也能本地跑推理模型。R1 发布后官方 App 一度冲到美国区 App Store 免费榜第一。

## 为什么被反复提起

- **开源**：权重能直接下载，可以本地部署、可以微调，这对不想被 API 绑住的团队意义很大。
- **便宜**：API 定价长期显著低于同级模型，是很多人第一次用上「强模型」的原因。
- **推理能力**：R1 系列在数学、代码、逻辑题上的表现是它最被认可的地方。

## 说这些的时候注意

- 模型版本迭代很快，**具体型号、参数、价格、榜单成绩都会过期**，说之前先查当期信息。
- 开源协议在不同模型上不一样（有的 MIT，有的自有协议），商用前要核对具体那一个。
- 「成本几百万美元」是训练算力成本的口径，不等于总投入，引用时说清楚口径。
