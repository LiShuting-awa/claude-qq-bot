# 塔科夫的弹药与护甲

塔科夫的弹药系统是它最劝退也最核心的部分。规则不复杂，难的是型号太多。

## 两条独立的伤害线

每种子弹同时有两个关键属性：

- **穿透力（Penetration Power）**：能不能打穿护甲。
- **基础伤害 / 肉体伤害（Damage / Flesh Damage）**：打在没有护甲的部位上造成多少伤害。

这两条是互相矛盾的：**穿甲弹伤害通常低，高伤害弹往往穿不透护甲。**
所以选弹药的本质是选场合：

- 对面重甲 → 用高穿透弹，打穿之后靠它打身体。
- 对面没甲或用霰弹/手枪弹的近距离遭遇 → 高伤害弹更划算，打四肢和胸腹收益更大。

## 护甲等级怎么起作用

- 护甲分 **1 到 6 级**，等级越高越能挡住高穿透弹。
- 护甲有**耐久值**。每次挡住一次命中都会掉耐久，耐久低了防护就下降，
  最后会「打穿」甚至「过度穿透」（overpenetration，穿透后仍造成额外伤害）。
- **有效耐久**：护甲被修过之后，最大耐久会永久下降，所以反复修的老甲不如新的。
- 头盔同理，而且头盔有**跳弹**概率——低穿透弹打头盔可能被弹开，
  但被高穿透弹正面命中头部，多数头盔救不了你。

## 弹药命名的规律

- 俄系弹常用缩写：**PS / BT / BP / BS / PP / US / SP** 等，通常越靠后的越穿甲（也有例外）。
- 北约系用编号：**M855 / M855A1 / M995 / M80 / M62 / M61** 之类，
  同样大致是数字越大越穿甲，但**M855 和 M855A1 的差距非常大**，别以为是同一档。
- 霰弹、手枪弹里也有专门的穿甲型号（比如 AP 系列），近距离能打穿轻甲。
- 记住：**名字像不代表性能像**。真正要对比就看穿透力和伤害两个数。

## 实战结论

- 想稳：带能打穿你预计会遇到的最硬护甲的那种子弹。
- 想省钱：普通弹打四肢和脸，靠状态伤害（出血、骨折）拖死对面。
- 别囤一堆「看起来厉害」的弹却不知道穿透力，那是纯浪费。
- 具体数值每期都会调整，查的时候认准当期维基或弹药表，别用旧攻略的数字。
